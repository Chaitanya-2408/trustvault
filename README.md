
# TrustVault

Secure document sharing with document-level permissions,
immediate access revocation, and a tamper-evident audit trail.

## Technology stack

- Python and Flask
- React, TypeScript and Vite
- PostgreSQL
- pytest
- Git and GitHub

## Security principles

- Server-side document authorisation
- Private file storage
- Explicit per-document permissions
- Revocation checks on every protected request
- Auditing of successful and denied access attempts

## Project status

Under active development for the Snovasys hackathon.
